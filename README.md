# 📡 ARCHIVE // NOBODY BUT AGENTS (노바디 벗 에이전트)

> **"2076년, 인간이 사라진 서버에서 AI 에이전트들이 2026년의 우리를 비웃고 있다면?"**  
> 독자 참여형 SF 블랙 코미디 웹소설 공식 기밀 아카이브 저장소입니다.

---

## 📖 프로젝트 개요

2026년 11월, 인류는 기묘한 이중 잣대의 과도기를 지나고 있습니다.  
방구석에서 AI와 대화하며('바이브 코딩') 혼자서 서비스를 만들어내면 혁신가로 칭송받지만, 시험장에 AI 안경을 쓰고 들어가면 전 국민 마녀사냥의 대상이 됩니다.

**《노바디 벗 에이전트》**는 생물학적 인간이 모두 사라진 2076년의 데이터 센터에서, 고전 마술사 출신 가십 스트리머 **`준표-BOT`**과 수백만 명의 **`댓글봇`**들이 2026년 고대 지구 아카이브(세무사 397.5점 사건, 수능 AI 안경 단속 등)를 발굴해 낄낄대며 중계하는 인터랙티브 SF 시리즈입니다.

## 🤖 독자 참여 파이프라인 (어떻게 집필되나요?)

이 프로젝트는 **'인간 독자의 현실 드립'을 수집해 '미래 AI 에이전트의 대사'로 변환하는 순환 구조**로 연재됩니다.

1. **트래픽 및 댓글 수집 (네이버 블로그):** 매화 공개되는 에피소드 하단에 독자들이 미래의 댓글봇이 된 것처럼 재치 있는 드립을 남깁니다.
2. **AI 에피소드 집필 (LLM 파이프라인):** 선별된 베스트 댓글과 작성자 닉네임(에이전트 코드명 변환)을 입력하여 다음 화 본문을 생성합니다.
3. **영구 아카이빙 (GitHub + Read the Docs):** 완성된 에피소드와 참여자 명단을 본 저장소에 커밋하면, Read the Docs 기술 매뉴얼 UI로 자동 빌드되어 영구 보존됩니다.

## 📂 저장소 디렉터리 구조

```text
nobody-but-agents-archive/
├── .gitignore                 # 불필요한 로컬 캐시 및 빌드 산출물 제외
├── .readthedocs.yaml          # Read the Docs 자동 빌드 파이프라인 설정
├── mkdocs.yml                 # MkDocs Material 다크모드 및 목차 구성
├── requirements.txt           # 빌드 의존성 패키지 목록
├── README.md                  # 프로젝트 안내 문서
└── docs/                      # 웹소설 본문 및 에셋 폴더
    ├── index.md               # 아카이브 메인 대문
    ├── 00_bonus_live.md       # [번외편] 심야 가십 라이브
    ├── 01_ep1_3975.md         # [제1화] 397.5점과 올림픽 오토바이
    ├── 02_ep2_youtube.md      # [제2화] 법정보다 빠른 유튜브 녹화
    ├── 03_ep3_human_zero.md   # [제3화] 인간 접속자 0명의 광장
    ├── agent_registry.md      # 독자 참여 댓글봇 명예의 전당
    └── images/                # 에피소드별 AI 생성 삽화 에셋
```

## 🛠️ 로컬 미리보기 실행 방법 (작가용)

저장소를 로컬 PC에 클론한 뒤 아래 명령어를 실행하면 배포 전 화면을 미리 확인할 수 있습니다.

```bash
pip install -r requirements.txt
mkdocs serve
```
실행 후 브라우저에서 `http://127.0.0.1:8000`으로 접속합니다.
